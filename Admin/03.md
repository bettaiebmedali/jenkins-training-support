✅ 21 TP – 1 par Slot (Formation Jenkins 3 jours)

➡️ Tous les TP sont réalistes, orientés administration et CI/CD.
➡️ Prêts à être utilisés en formation.

🧩 Jour 1 — Fundations & Installation
🕐 Slot 1 – TP : Découverte de Jenkins

🎯 Objectif : comprendre l'interface & l’architecture

Exercice :

Ouvrir Jenkins et identifier :

Dashboard

Manage Jenkins

Permissions

Build Queue

Faire un schéma de l’architecture interne (Controller + Agents).

Relever les ports utilisés, les répertoires critiques (/var/lib/jenkins, /var/log/jenkins).

🕑 Slot 2 – TP : Installer Jenkins

🎯 Objectif : Installation propre + service systemd

Exercice :

Installer Jenkins sur Debian ou via Docker.

Activer et vérifier le service :

sudo systemctl status jenkins


Changer le port de Jenkins → redémarrer → vérifier.

🕒 Slot 3 – TP : Configuration initiale

🎯 Objectif : Configurer Jenkins après installation

Exercice :

Créer un admin sécurisé.

Installer les plugins recommandés.

Changer le thème (Dark Theme).

Activer/Examiner la sécurité CSRF & les crumbs.

🕓 Slot 4 – TP : Gestion Users & RBAC

🎯 Objectif : configurer une sécurité complète

Exercice :

Activer Jenkins Own User Database.

Installer Role Strategy Plugin.

Créer :

Groupe "dev"

Groupe "ops"

Donner :

dev : build, view

ops : admin

Tester avec 2 comptes différents.

🕔 Slot 5 – TP : Configuration d'un Agent SSH

🎯 Objectif : connecter un node esclave

Exercice :

Créer un nouvel agent permanent.

Déployer la clé SSH dédiée.

Connecter l’agent.

Lancer un job sur cet agent avec :

agent { label 'linux-node' }

🕕 Slot 6 – TP : Installer & gérer les plugins

🎯 Objectif : savoir contrôler le catalogue des plugins

Exercice :

Installer : Git, Pipeline, Credentials.

Rechercher un plugin obsolète.

Faire un rollback d’un plugin.

Exporter la liste complète des plugins en TXT.

🕖 Slot 7 – TP : Créer un Freestyle Job

🎯 Objectif : manipuler un job simple

Exercice :

Créer un job Freestyle.

Ajouter un SCM (GitHub public).

Ajouter un shell script :

echo "Build from Freestyle"


Déclencher le job manuellement.

Consulter les logs.

🧩 Jour 2 — Pipelines, GitHub, Docker, SonarQube, Shared Lib
🕐 Slot 8 – TP : Premier pipeline declarative

🎯 Objectif : créer un Jenkinsfile

Exercice :
Créer un pipeline simple :

pipeline {
  agent any
  stages {
    stage('Build') {
      steps { echo 'Hello from pipeline' }
    }
  }
}

🕑 Slot 9 – TP : Pipeline avancé (parallel + error handling)

🎯 Objectif : maîtriser la syntaxe avancée

Exercice :
Créer un pipeline parallèle :

parallel (
  unit_tests: { echo "Run tests..." },
  security_scan: { echo "Scanning..." }
)


Ajouter un try/catch avec currentBuild.result.

🕒 Slot 10 – TP : Credentials

🎯 Objectif : utiliser Jenkins Credentials

Exercice :

Ajouter un secret text dans Jenkins.

L’utiliser dans un pipeline :

withCredentials([string(credentialsId: 'API_KEY', variable: 'KEY')]) {
  sh 'echo "Key: $KEY"'
}

🕓 Slot 11 – TP : Mettre en place un Webhook GitHub

🎯 Objectif : trigger automatique

Exercice :

Activer build when a change is pushed.

Créer un Webhook sur GitHub :

URL Jenkins: /github-webhook/

Faire un commit → vérifier que Jenkins build automatiquement.

🕔 Slot 12 – TP : Intégration SonarQube

🎯 Objectif : analyser la qualité du code

Exercice :

Configurer le serveur Sonar dans Jenkins.

Lancer une analyse avec Maven :

mvn clean verify sonar:sonar


Ajouter waitForQualityGate.

Déclencher une erreur volontaire → voir le résultat.

🕕 Slot 13 – TP : Build & Push Docker

🎯 Objectif : Docker dans Jenkins

Exercice :

Créer un Dockerfile.

Build image dans pipeline :

docker build -t demo-app .


Pusher vers DockerHub via credentials.

🕖 Slot 14 – TP : Créer & utiliser une Shared Library

🎯 Objectif : réutilisation de code Jenkins

Exercice :

Créer repo Git jenkins-shared-lib.

Ajouter vars/hello.groovy.

Appeler la lib :

@Library('jenkins-shared-lib') _
hello("Jenkins")

🧩 Jour 3 — Administration avancée, Maintenance, Sécurité
🕐 Slot 15 – TP : Housekeeping & nettoyage

🎯 Objectif : maintenir un Jenkins propre

Exercice :

Supprimer builds anciens via Build Discarder.

Nettoyer workspaces :

rm -rf workspace/*


Vérifier la taille de /var/lib/jenkins.

🕑 Slot 16 – TP : Backup & Restore

🎯 Objectif : savoir restaurer après un crash

Exercice :

Installer ThinBackup.

Faire une sauvegarde complète.

Supprimer un job.

Restaurer le job via backup.

Vérifier que tout fonctionne.

🕒 Slot 17 – TP : Logs & Monitoring

🎯 Objectif : analyser un problème

Exercice :

Lire les logs dans :

/var/log/jenkins/jenkins.log


Générer une erreur volontaire.

Débugger à partir des logs Jenkins.

Activer Prometheus (si plugin dispo).

🕓 Slot 18 – TP : Gestion des plugins avançée

🎯 Objectif : diagnostique + rollback

Exercice :

Installer un plugin incompatible volontairement.

Observer logs d’erreur.

Désactiver le plugin.

Restaurer version antérieure.

🕔 Slot 19 – TP : Scaling – Ajouter plusieurs agents

🎯 Objectif : architecture distribuée

Exercice :

Créer 2 agents : docker + ssh.

Assignation des agents selon labels.

Exécuter pipeline distribué :

build sur agent1

tests sur agent2

🕕 Slot 20 – TP : Sécurisation avancée

🎯 Objectif : sécuriser un Jenkins en production

Exercice :

Activer HTTPS avec NGINX reverse proxy.

Désactiver l’inscription publique.

Régénérer un token API.

Activer audit logging.
