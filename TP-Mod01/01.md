# TP 1 : Installation et premier lancement de Jenkins

## 🎯 Objectifs
- Installer et lancer Jenkins via un conteneur Docker sur Codespaces.  
- Explorer l’interface utilisateur de Jenkins.  
- Créer un premier job Freestyle.

---
## 📌 Pré-requis
- Un compte GitHub (pour utiliser Codespaces).  
- Un accès à Docker Hub.  
- Notions de base sur Docker et les conteneurs.

---

## 🧩 Étape 1 : Lancer un Codespace avec Docker

1. Se connecter à GitHub et ouvrir un repository (existant ou nouveau).
2. Cliquer sur **Code > Codespaces > Créer un Codespace sur main**.
3. Une fois le Codespace ouvert, vérifier la disponibilité de Docker :

```bash
docker --version
``` 

## 🐳 Étape 2 : Installation de Jenkins via Docker
Télécharger et exécuter Jenkins dans un conteneur :

``` bash
docker run -d --name jenkins-lab -p 8080:8080 -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts
``` 

Vérifier que le conteneur est lancé :

``` bash
docker ps
```

Accéder à Jenkins via le navigateur :

``` arduino
http://localhost:8080
``` 
Récupérer le mot de passe administrateur :

``` bash
docker exec jenkins-lab cat /var/jenkins_home/secrets/initialAdminPassword
```
- Suivre l’assistant d’installation :

- Coller le mot de passe dans Jenkins.

- Choisir Installer les plugins recommandés.

- Créer un utilisateur administrateur.

## 🖥️ Étape 3 : Exploration de l’interface utilisateur
Identifier les principaux éléments :
 - Tableau de bord : vue globale des jobs.

 - Gérer Jenkins : configuration, sécurité, outils, plugins.

 - Historique des builds : liste des exécutions passées.

- Console output : logs détaillés des jobs.

## 🛠️ Étape 4 : Création d’un premier job Freestyle
- Cliquer sur Nouveau Item.

- Nommer le job MonPremierJob.

- Sélectionner Projet Freestyle, puis valider.

- Dans la section Build, ajouter une étape Exécuter un script shell :

``` bash
echo "Hello Jenkins! Mon premier job fonctionne !"
```
- Sauvegarder puis exécuter le job.

- Vérifier les logs et la sortie dans la console.

### 🎉 Félicitations ! Tu viens de lancer ton premier job Jenkins.
