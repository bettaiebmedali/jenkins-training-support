# 🎉 Plugins Rigolos pour Jenkins (TP Fun)

Voici deux plugins **vraiment drôles et inutiles**, parfaits pour détendre l’ambiance pendant une formation Jenkins 😄

---

## 1️⃣ Chuck Norris Plugin 🥋🤣

### 📌 Description
Ce plugin affiche une **blague Chuck Norris** différente à chaque recharge de la page Jenkins.  
Totalement inutile. Absolument indispensable.

### 🔧 Installation
1. Aller dans : *Manage Jenkins* → *Manage Plugins*
2. Onglet : *Available*
3. Chercher : **Chuck Norris Plugin**
4. Installer + Redémarrer Jenkins

### 🎯 Résultat
Une tête de Chuck Norris apparaît dans votre tableau de bord Jenkins, avec une punchline du style :

> “Chuck Norris can approve a failing build.”

---

## 2️⃣ Nyan Cat Plugin 🌈🐱🎵

### 📌 Description
Ce plugin remplace les barres de progression Jenkins par…  
**Nyan Cat qui traverse l’écran en laissant une traînée arc-en-ciel.**

Oui, ça existe.  
Oui, ça marche vraiment.  
Oui, c’est incroyable.

### 🔧 Installation
1. Aller dans : *Manage Jenkins* → *Manage Plugins*
2. Onglet : *Available*
3. Chercher : **Nyan Cat Plugin**
4. Installer + Redémarrer Jenkins

### 🎯 Résultat
Pendant qu’un job tourne, une animation Nyan Cat s’affiche sur la page du build.  
Productivité : −80%  
Fun : +250%
